# 导航入口展平纲要

2026-09-07｜分支：`codex/flatten-navigation`｜状态：第 3 步完成，待用户验收；第 4 步尚未开始

已确认：现有面包屑通过 `from` 保存进入路径，结合 `sort/sorts` 恢复排序，并已有根入口及各列选中逻辑。本次复用该机制，将结果接到统一第一列，清除主菜单另用 `nav_primary` 判断归属的分支。

第一列复用第二、三列的 `grid-title-cell.html`、`collection/item-content.html` 和 `collection-list.css`，沿用行结构、图标、间距、悬停及 `.is-current` 选中态；适配容器与断点限制。统一入口列表保持完整，来源变化只更新选中项，避免原根菜单渲染函数把它替换成局部菜单。

目标入口：目录、阅读目的、标签、全部文章、产品－分类、产品－全部、系统－语言、系统－外观、系统－我的、系统－站点。

实施顺序：

1. **站点归组（已完成）**：建立 `site/`，同步迁移项目与主题的关于、更新记录及项目微信页面，保留原网址，更新内容路径引用。
2. **产品整理（已完成）**：建立产品全部及分类入口，免费／付费、自建／第三方分别按价格和来源筛选，产品内容保持一份。
3. **系统页面（已完成）**：完成语言、外观及现有“我的”页接入，再完成站点页的版本与更新操作，同属第 3 步验收。复用已有偏好和更新逻辑，将操作逻辑与下拉菜单的 DOM、脚本加载条件分开；全站主题初始化、跟随系统、语言推荐及更新提示继续有效。语言页保留原阅读页面及其导航状态，切到对应译文；设置页返回上下文独立于文章的 `from`，不混用。“我的”保持现有功能范围，不扩成账户系统。旧控件呈现在第 4 步删除，共存期间共用操作逻辑。
4. **入口切换**：合并 `Home.Pages` 与父页面为首页的分类法根，使用 `LinkTitle`／`Title`、`RelPermalink`、`weight` 生成十个入口，补齐前四项的多语言名称与顺序。不能只取 `Home.Sections`，也不能只取 `Site.Pages`：后者不包含 `build.list: local` 的系统操作页。第一列完整列表保持稳定，已有 `from` 只决定选中项，直接访问按内容祖先确定入口；同批替换静态模板、首帧预览与运行时根导航，删除旧导航片段、菜单归属和导航专用声明。系统链接继续携带独立的 `return` 上下文。保留集合定义、产品属性及仍有用途的正文／页脚配置。
5. **布局合并**：采用一套列布局，先确定统一画幅的横向滚动容器，再同步合并 CSS、JS 断点及首屏列数预留；与第 4 步避免重复根导航 DOM 的工作衔接。窄屏初次打开文章应让正文进入视野，返回时恢复前页画幅位置；正文保持可读行宽，代码块、表格和图片按内容需要处理溢出。更新原“小屏不得横向溢出”的回归断言，验证内容可达性与首帧稳定性。
6. **配色收敛**：统一黑白灰及交互状态，保留清楚的选中态和键盘焦点。

每步保持可运行并独立提交，用户确认后再进入下一步。复用现有回归，验证多语言、进入路径、排序、前进后退和系统操作；补充新入口及各宽度下的视觉核对。主题能力在本目录所属主题实现，业务内容在项目根目录同步；使用根目录内容测试，忽略 `exampleSite`。

第 2 步后复核：六步顺序仍成立，前两步无需返工。三种语言的实际 Hugo 页面集合均有七个可列出的根入口：`d/`、`intent/`、`tags/`、`all/`、`product-categories/`、`products/`、`site/`；`my/` 已存在但 `build.list: never`，语言与外观页尚未建立。前四个入口的 `weight` 目前均为 0，需要在入口切换时补齐。`fragments/` 等内部节点沿用已有不可列出规则。

后续验收重点：第 3 步验证跨语言返回、缺失译文、偏好刷新、全站跟随系统、检查更新与更新提醒；若修改 `sw-manager.enable.update.js`，同时执行 AGENTS.md 第 9 条规定的缓存及更新验证。第 4 步验证文章从目录／标签／全部／产品分类进入时，第一列始终完整、选中正确，刷新和前进后退不回写旧菜单。第 5 步在 390、1024、1440 宽度验证同一列结构、阅读与返回位置、触摸及键盘可达。第 6 步的黑白灰配色与浅色／深色／跟随系统偏好分别处理。
