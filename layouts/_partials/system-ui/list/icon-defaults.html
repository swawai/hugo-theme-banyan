{{- $page := .page -}} {{- $defaults := dict -}} {{- $candidates := slice $page -}} {{- range $page.Ancestors -}}{{- $candidates = $candidates | append . -}}{{- end -}} {{- range $candidate := $candidates -}} {{- range $kind := slice "folder" "file" -}} {{- if not (isset $defaults $kind) -}} {{- $field := printf "list_icon_%s" $kind -}} {{- if isset $candidate.Params $field -}} {{- $icon := partial "system-ui/icon/page-value.html" (dict "value" (index $candidate.Params $field) "page" $candidate) -}} {{- if $icon -}}{{- $defaults = merge $defaults (dict $kind $icon) -}}{{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return (merge (dict "folder" "folder" "file" "file") $defaults) -}}
